## Описание PR

Реализует задачу P1 «Ярмарка 4 сезона»: публичный раздел «Мероприятия» и закрытый кабинет администратора.

**Что добавлено**
- Публичная афиша `/events.html`: календарь, предстоящие/архив, карточки, фотогалерея, документы, адаптивная мобильная версия.
- Пункт «Мероприятия» в основное меню (`index.html`, `participants.html`).
- Кабинет `/admin/`: вход по логину/паролю, боковое меню (Главная/Мероприятия/Реестр/Выход), дашборд, управление мероприятиями (создание, редактирование, обложка, фото, документы, предпросмотр, публикация/снятие, архив, удаление) и реестром (поиск по наименованию и ИНН, добавление/редактирование, статус, архив, импорт/экспорт Excel, журнал изменений).
- Бэкенд Supabase: схема, RLS, представление `public_registry`, триггеры журнала, хранилище, seed (102 записи реестра).
- Локальный сервер и приёмочные проверки (`tools/`), отчёт и снимки.

**Безопасность**
- Серверная авторизация и RLS; публичный доступ только к опубликованным мероприятиям и полям `name`/`products`; ИНН и контакты — только администратору; журнал изменений реестра; проверка загружаемых файлов.

**Проверено**
- 13/13 приёмочных проверок (headless Chrome): полный цикл создания/публикации/отображения, редактирование реестра, поиск по ИНН, доступ без авторизации → 401, мобильная адаптация 320/390 px.

**Не проверено / далее**
- Публикация на домене и боевом Supabase (нужен проект и ключи); реальный импорт полного реестра с ИНН — выполняется позже через админку.
