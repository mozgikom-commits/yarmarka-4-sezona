## Описание PR

Реализует задачу P1 «Ярмарка 4 сезона»: публичный раздел «Мероприятия» и закрытый кабинет администратора.

**Что добавлено**
- Публичная афиша `/events.html`: календарь, предстоящие/архив, карточки, фотогалерея, документы, адаптивная мобильная версия.
- Пункт «Мероприятия» в основное меню (`index.html`, `participants.html`).
- Кабинет `/admin/`: вход по логину/паролю, дашборд, управление мероприятиями (создание, редактирование, обложка, фото, документы, предпросмотр, публикация/снятие, архив, удаление) и реестром (поиск по наименованию и ИНН, добавление/редактирование, статус, архив, импорт/экспорт Excel, журнал изменений).
- Бэкенд **REG.RU (PHP 8.1+ / PDO SQLite)** в каталоге `php/` (фронтенд остаётся статическим на GitHub Pages → iframe Tilda): REST с маршрутами относительно точки монтирования — на боевом REG.RU это изолированный `/fair-api/` на `mozgikomlab.ru` (без отдельного поддомена и расширения тарифа), схема, seed (102 записи реестра), журнал изменений, загрузка файлов. Прежний план Supabase отменён владельцем.

**Безопасность**
- `password_hash`/`password_verify`; надёжный уникальный пароль администратора.
- Серверные сессии (токен в `Authorization`, в БД только `hash('sha256', token)`), ограничение жизни сессии.
- CSRF (`X-CSRF-Token` + проверка `Origin`), ограничение входа (5 попыток за окно → 429).
- Проверка загружаемых файлов (белый список MIME/расширений, лимиты, файлы вне webroot, `nosniff`).
- Публичный доступ только к опубликованным мероприятиям и полям `name`/`products`; ИНН и контакты — только администратору; роли `admin`/`editor` (editor — только мероприятия); журнал изменений.
- Данные и конфиг в `yarmarka-private` **вне webroot** (изолированы от LAB/Межгорода); `.env`/секреты в git не попадают.

**Проверено**
- API E2E `tools/qa/php-api-e2e.cjs` (health, публичные данные, авторизация, CSRF, CRUD, журнал, загрузка, ограничение входа) — 26/26 при монтировании `/fair-api`.
- Браузерный E2E `tools/qa/php-frontend-e2e.cjs` (афиша, реестр 102, документы без авторизации, вход, цикл создание→публикация→показ, поиск по ИНН, мобильная 390px) — 15/15 при монтировании `/fair-api`, включая CORS (кросс-доменный фронтенд).
- CORS: разрешённый Origin получает ACAO, посторонний — нет (изменяющие методы → 403); предварительный OPTIONS — 204.
