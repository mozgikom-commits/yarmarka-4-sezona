# Отчёт о приёмке — «Ярмарка 4 сезона»: мероприятия и административная панель

- **Задача:** P1. Публичный раздел «Мероприятия» (`/events`) и закрытый кабинет администратора (`/admin`) с реестром участников.
- **Ветка:** `feature/fair-admin-events` (репозиторий `mozgikom-commits/yarmarka-4-sezona`).
- **Дата:** 25.11.2026.
- **Статус:** реализовано и проверено локально; merge и публикация не выполнялись (по инструкции).

## 1. Что изменено

### Публичный раздел «Мероприятия»
- `events.html`, `events.css`, `events.js` — афиша: календарь с подсветкой дат, фильтры «Все / Предстоящие / Архив», карточки (фото, название, дата, время, описание, место), фотогалерея прошедших мероприятий, прикреплённые документы, адаптивная мобильная версия.
- `data/events.json` — стартовые демо-мероприятия (fallback без бэкенда).
- Пункт «Мероприятия» добавлен в меню `index.html` и `participants.html`.

### Кабинет администратора `/admin/`
- `admin/index.html`, `admin/admin.css`, `admin/admin.js`, `admin/excel.js`.
- Вход по логину/паролю; боковое меню «Главная / Мероприятия / Реестр / Выход».
- Главная: счётчики (опубликовано мероприятий, участников реестра, ближайших), быстрые кнопки, список ближайших мероприятий.
- Мероприятия: создание/редактирование, дата/время/место, загрузка обложки, фотографий галереи и документов, предпросмотр черновика, публикация/снятие, архив, удаление с подтверждением.
- Реестр: поиск по наименованию и ИНН, добавление/редактирование, статус (действующий/архив), архивирование, импорт/экспорт Excel (CSV/XLSX), журнал изменений.

### Бэкенд и данные
- `supabase/migrations/20261125000000_init.sql` — схема (`events`, `event_photos`, `event_documents`, `registry`, `change_log`, `admin_users`), RLS (публичное/служебное разграничение), представление `public_registry`, триггеры журнала и `updated_at`, хранилище.
- `supabase/seed.sql` — 102 записи реестра (реальные `name` + `products`, служебные поля пустые) и демо-мероприятия.
- `supabase/functions/upload-asset/index.ts` — серверная проверка файлов (MIME/размер) перед загрузкой.
- `js/fair-config.js`, `js/fair-data.js` — единый слой доступа (static / supabase / local).
- `tools/local-server/server.mjs` — локальный сервер для приёмки (серверная авторизация, хранение, журнал, проверка файлов).
- `tools/qa/acceptance.cjs`, `tools/qa/screenshots.cjs` — проверки и снимки.
- `docs/ADMIN_SETUP.md` — инструкция по подключению Supabase.

### Сохранено
- Фирменный стиль (кремовый фон, зелёный `#267437`, оранжевый `#ef7900`, шрифты Arial/Georgia, mobile-first).
- Публичный реестр по-прежнему показывает только `name` + `products`; ИНН и служебные данные не публикуются.
- Существующая структура и данные реестра (102 записи) не изменены.
