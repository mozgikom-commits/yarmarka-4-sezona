# Итоговый QA-отчёт — ярмарка «4 сезона»

Обновлено: 17 ноября 2026 г.

## Итог реестра

- Источник: исходный JSON и резервная таблица проекта, по **102 записи** в каждом.
- Сверка исходных пар «наименование + ИНН»: **102/102** совпали между архивами. ИНН использовался только для внутренней проверки и удалён из публичного сайта и JSON.
- По исходному архиву подтверждены **6 записей организаций**: 5 ООО и 1 сельскохозяйственный потребительский перерабатывающий кооператив. Наименование и ассортимент этих шести записей совпали с резервной таблицей.
- Публично размещены **6 из 102** участников. В каждой карточке показываются только два поля: **наименование** и **продукция**. Поиск работает по названию и ассортименту; добавлен фильтр по категориям.
- **96 записей не размещены:** 45 записей ИП, 46 ЛПХ и 5 записей без организационно-правовой формы содержат имена физических лиц. В архиве проверенной формы согласия на публикацию этих персональных данных для неограниченного круга лиц нет.
- Официальная политика, оферта и найденный шаблон согласия описывают регистрацию/учёт участника, заявку, договор, взаимодействие и обработку данных. Явного разрешения на распространение имени участника вместе с ассортиментом в интернете не найдено. Само утверждение владельца о принятии оферты и политики подтверждает принятие этих документов, но в проверенных текстах документы не содержат соответствующего условия о публикации.
- Согласие на обработку персональных данных для распространения должно быть отдельным; если из согласия не следует разрешение на распространение, закон предусматривает обработку без права распространения. См. [ст. 10.1 закона № 152-ФЗ на сайте Минтруда России](https://mintrud.gov.ru/docs/laws/130), части 1 и 4.
- ФНС предоставляет сведения ЕГРИП/ЕГРЮЛ как открытые и общедоступные для использования в информационных системах, с предусмотренными законом исключениями. Но индивидуальная актуальная проверка 45 записей ИП не выполнена, а найденный комплект не показывает основание для размещения списка ЛПХ/прочих записей. См. [порядок доступа ФНС к ЕГРЮЛ/ЕГРИП](https://www.nalog.gov.ru/rn77/service/egrip2/access_order/).
- Для поимённой проверки остаётся получить текущие выписки/официально подтверждённые сведения ЕГРИП по ИП или документ о распространении, в котором прямо охвачены публикация имени и ассортимента на сайте организатора. Для ЛПХ и остальных записей требуется отдельное подтверждённое основание для раскрытия их имён.
- Продукцию и наименования не выдумывали; исходные архивы не изменяли.

### Публичный реестр

Файл: `data/participants-public.json`. Каждая запись содержит только `name` и `products`. ИНН удалён из файла, карточек, поиска и клиентского кода. Дополнительные сведения источника (адреса, телефоны и другие поля) сайт не загружает.
