- Покупатели: 08:00–19:00.
- Участники: 07:00–08:00 — заезд и подготовка; 08:00–19:00 — торговля; 19:00–20:00 — уборка, погрузка и выезд.

Предыдущая попытка повторной публикации была остановлена дополнительной автоматической проверкой содержания, а не отсутствием разрешения владельца. Точный код правила/текст отказа не доступен в репозитории или подключённом GitHub API. В архивном содержимом есть идентифицирующие/контактные данные; повторная публикация не выполнялась и ограничение не обходилось. |

Чтобы опубликовать документы неизменёнными, требуется решение проверки, явно разрешающее распространение именно оригинальных файлов с находящимися в них персональными/идентифицирующими сведениями, либо оригиналы, для которых такая публикация уже официально разрешена. Явного разрешения владельца достаточно для его согласия, но оно само по себе не снимает автоматическое ограничение публикации.

## Мобильная адаптация

CSS для главной, расписания и реестра сохраняет Mobile First компоновку. Однако в этой среде браузерные DevTools/управление точным размером viewport недоступны, а системный запуск headless Chromium ранее заблокировался политикой среды. Поэтому точные визуальные проверки и скриншоты на запрошенных размерах не заявляются; реальные устройства также не использовались.
