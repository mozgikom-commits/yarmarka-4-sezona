# Отчёт: исправление самопроизвольной прокрутки

**Проект:** Ярмарка «4 сезона»  
**Дата:** 19 ноября 2026  
**Ветка:** `main`  
**Действующий сайт:** https://xn--4-8sboi4afs.online/  
**Источник страниц:** GitHub Pages внутри Tilda T123

## 1. Установленная первопричина

Проблема возникала на стыке iframe GitHub Pages и страницы Tilda:

- В `app.js` одновременно находились логика интерфейса и мост прокрутки. Мост отправлял родительской странице сообщения о прокрутке во время загрузки, смены якоря, истории браузера и повторного таймера. Обработчик T123 выполнял каждое такое сообщение через `window.scrollTo`.
- T123 менял высоту iframe по сообщениям дочерней страницы, но не управлял восстановлением позиции при переходе iframe на другой HTML-документ. В результате позиция родительской страницы могла сохраняться от предыдущего документа и восстанавливаться браузером после перезагрузки.
- Дополнительно фильтр сообщений сравнивал полный URL. Ссылка с якорем, например `#registry`, переставала совпадать с текущим URL страницы и её команда прокрутки отбрасывалась.

Это была совокупная ошибка маршрутизации и синхронизации двух прокруток, а не ошибка отдельного элемента дизайна.

## 2. Что изменено

- Вынесена навигационная связь iframe в отдельный `navigation.js`. Высота передаётся отдельно; команда прокрутки отправляется для явного якоря или навигационного события, а не при каждом обновлении высоты.
- В T123 добавлены проверка источника и origin сообщений, ручное управление восстановлением позиции, сброс к началу при переходе между документами и сохранение позиции по маршрутам для «Назад»/«Вперёд».
- Сравнение маршрутов игнорирует фрагмент URL, поэтому команды якорей принимаются.
- Обновлены версии скриптов в загрузчиках страниц, чтобы браузер не использовал закэшированные обработчики.
- Сохранены резервные копии исходных файлов и прежнего T123 до правок.

**Файлы GitHub Pages:** `app.js`, `navigation.js`, `index.html`, `participants.html`, `docs/docs-citizens.html`, `docs/docs-ip.html`, `docs/docs-legal.html`, `docs/public-offer.html`, `docs/privacy-policy.html`, `tilda-loader-template.html`.

**Tilda:** изменён только существующий блок T123 страницы «Продовольственная ярмарка „4 Сезона“» (ID страницы 289692609, проект 45854209). Другие проекты, включая «Межгород Онлайн», не затрагивались.

## 4. Результаты браузерной проверки

Проверки выполнены в Chrome в браузере с окном 1363 × 936 px.

- Первое открытие и чистая перезагрузка действующего сайта: содержимое начинается с верхней позиции.
- Якоря «Участие», «Документы», «Реестр участников», «Отзывы», «Контакты» доводят до соответствующих разделов.
- Переход с главной на полный реестр открывает каталог с 102 участниками; высота iframe увеличивается, родительская страница остаётся вверху.
- Фильтр реестра по «Рубан» показывает одну запись и не меняет позицию родительской страницы.
- Публичная оферта и политика конфиденциальности открылись внутри действующего сайта. Проверены переход к документам и возврат на главную.
- Прямое открытие на GitHub Pages проверено для каталога, публичной оферты, политики конфиденциальности и трёх страниц перечней документов. Каждая страница открылась с `scrollY = 0`; каталог показал 102 из 102 записей.
- Кнопки браузера «Назад» и «Вперёд» вернули предыдущий документ и маршрут главной с ожидаемой позицией.
- При прокрутке к изображениям высота iframe изменилась с 6346 до 6350 px, затем осталась стабильной; положение у целевого раздела не изменилось.
- Проверен переход на действующем домене Tilda, а не только на GitHub Pages.

Во время одного измерения через вложенный iframe-локатор тестовый браузер показал прокрутку родителя до 2705 px. Чистая перезагрузка без этого измерительного действия сразу и в последующих замерах возвращала страницу к 0 px; обычными переходами это смещение повторить не удалось.

## 5. Ограничения

Не выполнена проверка реальных устройств Android и iPhone и отдельных ширин 360, 375, 393, 430, 768 и 1440 px: доступная браузерная среда не предоставила управление шириной viewport и эмуляцию Safari/iOS. Результаты выше относятся к Chrome при 1363 × 936 px.
