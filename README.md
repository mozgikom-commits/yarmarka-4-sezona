# Ярмарка «4 сезона»

Отдельный репозиторий сайта ярмарки во Владивостоке.

## Статус

Подготовка миграции с Tilda. **Действующий сайт пока не переключён.**

## План

1. Перенести оригинальный экспорт и восстановленные документы (юридические лица, ИП, ЛПХ/КФХ, оферта, политика), исходные ссылки и реестр 102 участников.
2. Объединить восстановленное содержимое с утверждённым дизайном.
3. Настроить HTTPS-публикацию из GitHub.
4. Протестировать страницы и ссылки, после чего заменить Tilda T123 на загрузчик.

Не смешивать с `mezhgorod-online`.
