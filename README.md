# Ярмарка «4 сезона»

Статический сайт ярмарки во Владивостоке. GitHub Pages публикует ветку `main` из корня репозитория по адресу https://mozgikom-commits.github.io/yarmarka-4-sezona/.

## Исходники

- `index.html`, `styles.css`, `app.js` — сайт и интерактивные разделы.
- `assets/` — фирменный знак, favicon и оптимизированные локальные иллюстрации.
- `data/participants-public.json` — отдельный источник сведений реестра, разрешённых для публикации.
- `tilda-loader-template.html` — шаблон загрузчика для тестирования Tilda T123; действующие блоки этим обновлением не меняются.

## Публикация

Изменения ветки `main` публикуются GitHub Pages. Действующий домен и блоки Tilda не редактируются этим коммитом. Поскольку страница Tilda уже загружает адрес GitHub Pages через iframe, опубликованная версия Pages автоматически отображается внутри этого iframe.

## Реестр

В резервном исходном архиве обнаружено 102 записи. Публичный массив пока пуст: состав сведений, разрешённых к открытому размещению, требует подтверждения. Не добавляйте идентификаторы и контактные данные без отдельной проверки.

## Юридические материалы

Имеющиеся документы и исходные данные в репозитории сохранены. Полные юридические HTML-страницы и ссылки на формы в текущую версию сайта не включены; доступность оригинальных материалов требуется согласовать. См. статус в `DESIGN_IMPLEMENTATION_REPORT.md`.

## Иллюстрации

Сгенерированные изображения используются только как иллюстрации и не изображают реальных участников ярмарки. Подробности указаны в `assets/ASSET_NOTES.md`.
