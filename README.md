# Ярмарка «4 сезона»

Статический сайт ярмарки во Владивостоке. GitHub Pages публикует ветку `main` из корня репозитория: https://mozgikom-commits.github.io/yarmarka-4-sezona/.

## Исходники

- `index.html`, `styles.css`, `app.js` — главная, mobile-first стили и интерактивные разделы.
- `assets/` — фирменный знак, favicon, локальные иллюстрации и адаптивные WebP-размеры.
- `data/participants-public.json` — отдельный источник только разрешённых публичных полей реестра.
- `docs/docs-legal.html`, `docs/docs-ip.html`, `docs/docs-citizens.html` — оригинальные перечни документов участников с прямыми ссылками на формы.
- `docs/documents.css` — адаптивное оформление страниц документов.
- `tilda-loader-template.html` — тестовый шаблон T123; настройки действующей страницы Tilda этим обновлением не меняются.

## Публикация

Изменения `main` публикуются GitHub Pages. Действующий домен уже загружает эту страницу через iframe; он использует обновлённую версию Pages автоматически после её публикации. Блоки Tilda не менялись.

## Юридические материалы

Оферта открывается из исходного публичного PDF организатора. Полные страницы участия доступны на сайте. Политику обработки персональных данных пока не публикуем: её оригинальная страница остановлена дополнительной проверкой, повторно обходить её не будем.

## Реестр

В локальном резервном архиве обнаружено 102 записи. Публичный массив пока пуст: состав разрешённых к открытому размещению сведений не подтверждён. Не добавляйте контактные или личные идентификаторы без отдельной проверки.

## Иллюстрации

Изображения фермеров и продукции сгенерированы как иллюстрации, не изображают реальных участников ярмарки и не подтверждают наличие конкретных товаров. Подробности указаны в `assets/ASSET_NOTES.md`.
